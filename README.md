# oka

個人開発で [oka-project.com](https://oka-project.com/) を運営しています。
「もっとワクワクを、広げる。」——実際の不便から生まれた、登録不要で使える小さなWebツールを作って公開しています。

## 公開中のツール

- **[Markdown Viewer](https://oka-project.com/tools/markdown-viewer)**
  mdファイルやテキストをその場でプレビュー。表示切替・HTMLコピー・印刷（PDF保存）に対応。
- **[Yomu](https://oka-project.com/tools/markdown-editor)**
  Markdownを書いて、note・WordPress・はてなブログ・Zenn・Word などへ、公開先に合わせて変換・書き出しできるエディタ。登録もインストールも不要。

ツールの一覧: [oka-project.com/tools](https://oka-project.com/tools/)
