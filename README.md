# oka

> **もっとワクワクを、広げる。**

知らなかったから選べなかったものを、選べるように。  
使いにくくて諦めていたことを、試せるように。

個人開発で [oka-project](https://oka-project.com/) を運営しています。ブラウザで使える小さなWebツールやゲームをつくり、VRChatのワールド紹介メディアを運営し、制作の過程も記録しています。

[Webサイト](https://oka-project.com/) ・ [ツールを使う](https://oka-project.com/tools/) ・ [制作物](https://oka-project.com/works) ・ [考え方・自己紹介](https://oka-project.com/about)

## なぜ、つくるのか

きっかけの一つは、VRChatで初心者を案内していたときの経験です。魅力的なワールドでも、存在を知らなければ出会えない。有名なワールドさえ、必要としている人に届いていないことがありました。

そこで、実際に訪れた場所を写真と言葉で残す「oka-vrc旅行記」を始めました。Webツールづくりも根っこは同じです。見つからないものには出会える入口を、使いづらいものには試せる手段をつくりたい。

**誰かの「できない理由」を一つ減らし、選べる可能性を一つ増やす。** それが、活動の形が変わっても共通している考え方です。

## 公開しているもの

### 使うためのWebツール

| ツール | できること |
| --- | --- |
| [Yomu](https://oka-project.com/tools/markdown-editor) | Markdownを書き、note・WordPress・はてなブログ・Zenn / Qiita・Wordなどへ、公開先に合わせて書き出す。 |
| [Markdown Viewer](https://oka-project.com/tools/markdown-viewer) | `.md`ファイルやテキストをすぐにプレビュー。HTMLコピーやPDF保存にも対応。 |
| [Karuku](https://oka-project.com/tools/image-resize) | 画像の圧縮・リサイズ・形式変換。用途や容量制限に合わせて整える。 |
| [Tojiru](https://oka-project.com/tools/pdf-merge) | PDFを結合・分割・並べ替え・回転。ファイルをアップロードせずに操作できる。 |

公開中のWebツールは、アカウント登録・インストール不要で利用できます。最新の一覧は [oka-project tools](https://oka-project.com/tools/) にまとめています。

便利さだけでなく、少し変わった発想も試しています。たとえば、積んでは崩されるブラウザゲーム [「賽ノ河原」](https://oka-project.com/tools/sai-no-kawara) も、その一つです。

### 見つけるためのメディア

**[oka-vrc旅行記](https://oka-project.com/works/oka-vrc)** は、VRChatのワールドを実際に訪れて、写真と体験をもとに紹介するメディアです。景色や遊び方だけでなく、一人でも楽しめるか、Questで訪れられるかなど、「行ってみたい」を行動に変えるための情報を残しています。

## つくるときに考えていること

**すぐ試せること。** 登録やインストールを必要としない、迷わず触れる入口を重視しています。公開中のブラウザ完結型ツールでは、入力内容やファイルを変換・処理のためにサーバーへ送らない設計を採用しています。データの扱いは各ツールのページにも明記しています。

**つくって終わりにしないこと。** 公開後も使いにくさや分かりにくさを見直し、必要なら直します。機能を増やすこと自体より、実際の不便が減ることを優先します。

**AIを使っても、考えることは手放さないこと。** AIは実装や調査、検証を進めるために積極的に活用しています。一方で、何を解決するか、どんな体験にするか、何を公開するかは自分で判断しています。

## 開発・関心領域

公式サイトは **Astro（SSR）・TypeScript** を使用し、**Cloudflare Workers / D1** などで運用しています。ツール群はHTML・CSS・JavaScriptを中心に、必要な機能をブラウザ側で動かす構成です。

関心があるのは、ブラウザ完結の道具、迷いにくいUI、情報の見つけやすさ、AIを活用した調査・開発・運用の仕組みづくり。分野を一つに限定せず、実際に気になったことを調べ、試し、公開しています。

> 気になる → 試す → つくる → 書く → 出す → また気になる。
